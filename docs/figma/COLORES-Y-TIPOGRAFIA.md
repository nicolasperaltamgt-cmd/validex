# Validex: colores y tipografía para Figma

## Colores
| Nombre | Hex | Uso |
|---|---|---|
| Tinta | #1a1033 | Texto principal, botones |
| Tinta suave | #4a4268 | Texto secundario |
| Apagado | #6b6488 | Textos chicos |
| Papel | #ffffff | Fondo general |
| Panel | #ece6ff | Secciones violeta claro |
| Línea | #cbbff0 | Divisores |
| Violeta de marca | #5b3df5 | Acentos, palabras destacadas |
| Violeta oscuro | #4528d4 | Texto de acento |
| Violeta profundo | #2b1a8f | Bloques grandes, contorno de recuadros |
| Violeta claro | #d9ceff | Resaltado sobre violeta profundo |
| Peligro | #c62828 | Pérdidas y errores |

Fondo de las pantallas de la app (Drop, Tantear, Importador, Guardados): #d9ceff, con tarjetas blancas.

## Tipografía
Segoe UI Variable / Segoe UI / system-ui. Títulos en peso 900, tamaño 48 a 60 px en escritorio y 30 px en celular.

## Forma
Botones en píldora (radio total). Tarjetas con radio 32 px y contorno de 2 px en #2b1a8f.

## Cómo pasar la página a Figma
1. Abrí Figma y usá el plugin "html.to.design" (de divRIOTS).
2. Pegá la dirección https://validex-prueba.netlify.app y elegí ancho 1440 (escritorio) y 390 (celular).
3. Repetí con /hoy, /tantear, /importador y /guardados.
4. Las fotos están en la carpeta imagenes y el logo en logo-validex.svg.
